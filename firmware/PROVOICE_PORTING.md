# ProVoice Reborn porting notes

The upstream First Byte ProVoice Reborn source is pinned as the
`vendor/provoice-reborn` Git submodule. Retroreader's ESP32 port is exposed as
**Monologue** and uses the compact XEN11K8 English voice at 11,025 Hz.

## Useful integration surface

The reader's speech abstraction needs blocking PCM generation, and ProVoice
already exposes the right conceptual path:

1. `TextToPhonetics` converts text in writable buffers.
2. `OpenBackend` starts a memory render.
3. Repeated `GetPCMdata` calls return PCM without using the Windows playback
   implementation.
4. `CloseBackend` releases the render.

The backend reports each voice's mono PCM format through `GetFontWaveFormat`.
ProVoice exposes volume, pitch, speed, base pitch, sentence pause, dictionary
activation and voice selection, which can map onto the reader's engine-specific
speech-settings menu.

## ESP32-S3 adaptation

- `main/monologue/` supplies only the Win32 types and resource calls needed by
  the recovered portable core; the Windows UI, threads and `waveOut` playback
  layer are not compiled.
- `monologue_port.c` maps the packed flash resources onto the engine's resource
  API and creates its speech control block.
- `speech_engine_monologue.c` implements the common Retroreader synthesis and
  settings interface, including native speed, pitch, dictionary processing and
  the added sentence-pause parameter 22.
- `voices/monologue-xen11k8.pack` contains the XEN11K8 speech-font resources and
  English dictionary in the compact `MONOVC1` container generated by
  `tools/pack_monologue_voice.py`.
- The reader consumes memory-rendered PCM through its existing buffered audio
  path; it does not use ProVoice's original playback implementation.
