Install Retroreader

Connect the 1.14-inch Freenove Media Kit with a data-capable USB cable. The web installer requires a browser with Web Serial support, such as desktop Chrome or Edge, and a secure web page.

If your browser does not support Web Serial, download the latest firmware and Windows installer from GitHub.

Troubleshooting

If connection fails, hold BOOT, briefly press RESET, release BOOT, then try again. If the installer finishes but the reader does not restart automatically, briefly press RESET. Flashing does not alter the SD card.
