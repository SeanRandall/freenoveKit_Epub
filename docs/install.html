Install Retroreader

Current prerelease: 2026.10.17, published 17 October 2026.

Prepare the SD card

A prepared microSD card is normally needed before first use. Download the Retroreader SD-card template, extract it, and copy the contents of the enclosed sd-card folder to the root of a FAT32-formatted card. The example configuration files contain no passwords or private service details. See Preparing the SD card for complete instructions.

Install the firmware

Connect the 1.14-inch Freenove Media Kit with a data-capable USB cable. The web installer requires a browser with Web Serial support, such as desktop Chrome or Edge, and a secure web page.

If your browser does not support Web Serial, download the newest alpha firmware and Windows installer from GitHub.

Choose a speech engine and voice

Open an engine below, then choose a voice variant. The same variants are included as downloadable firmware images.

Troubleshooting

If connection fails, hold BOOT, briefly press RESET, release BOOT, then try again. If the installer finishes but the reader does not restart automatically, briefly press RESET. Flashing does not alter the SD card.
